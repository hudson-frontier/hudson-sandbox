# Security reporting

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/hudson-frontier/hudsonbox/security/advisories/new). This sends the report privately to repository maintainers. Do not open a public issue containing vulnerability details, credentials, or customer data.

Include the affected commit/version, expected and observed behavior, reproduction steps, and potential impact. Use a minimal reproduction with synthetic data. Coordinate fixes and disclosure with maintainers through the private advisory; no response-time guarantee or bounty program is currently offered.

## Project status

Hudsonbox is at the design stage and has no supported runtime releases. Its documented auth, isolation, and recovery contracts have not been validated in a running implementation. Maintainers accept reports about the repository and security design; a supported-version policy will accompany runtime releases.
